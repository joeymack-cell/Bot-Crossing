# Contributing

This repository is the desktop fork of Bot Crossing. Report issues with this fork in this repository rather than the original author's project. Describe the app version, Windows version, steps to reproduce, and what you expected to happen. Remove private session titles, paths, prompts, and tokens from logs or screenshots before sharing them.

Use Node.js 24 or newer. Run npm ci, npm test, and npm run build. For visual changes, inspect the app with npm run desktop. Use temporary test sessions or fake records for automated checks; do not start real model tasks as a test.

Keep contributions focused and describe what was verified. Preserve the separation between local read-only scanning and explicit user actions. Keep the standalone all-project view and optional host project scope separate.

New code is contributed under the project's MIT license. Preserve original copyrights and record new asset/dependency licenses. Do not commit data, transcripts, browser profiles, secrets, generated packages, or node_modules.
